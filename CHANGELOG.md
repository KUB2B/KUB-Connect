# Changelog

## Unreleased

### Безопасность
- Windows: `wintun.dll` теперь ставится установщиком рядом с программой и
  грузится оттуда, а копия в пользовательском кэше сверяется по содержимому.
  Раньше подменённая DLL того же размера загружалась в процесс с правами
  администратора.
- Обновление: установщик проверяется по SHA-256 из релиза GitHub и
  скачивается в отдельный временный каталог; без контрольной суммы обновление
  не запускается.

### Исправления
- TUN: на сетях с IPv6 выбранные сервисы больше не идут мимо VPN — IPv6 на
  время подключения блокируется и в режиме «только выбранное» (как уже было
  в режиме «всё через VPN»); приложения переходят на IPv4.
- TUN: при смене сети (Wi-Fi ↔ кабель) приложение само переподключается.
  Раньше интернет пропадал, а статус оставался «Подключено».
- Выбор другого сервера при активном подключении сразу переключает
  соединение на него; удалить сервер, через который идёт соединение, нельзя.
- Журнал: при каждом подключении больше не повторяются строки прошлых
  сессий, файл `xray.log` не растёт бесконечно.
- Подключение не зависает надолго, если DNS не отвечает при определении
  адреса сервера.
- Если файл настроек повреждён, приложение сообщает об этом и указывает, где
  сохранена копия (раньше серверы молча пропадали).
- Linux: после аварийного завершения в TUN-режиме с kill switch правило
  firewall больше не остаётся висеть — оно снимается при следующем запуске
  от root.
- Linux: «Свернуть в трей» сворачивает окно, а не прячет его (трея на Linux
  нет, окно было не вернуть).
- Запуск: geo-базы больше не читаются в память целиком при каждом старте.
- Интернет больше не пропадает с `ERR_PROXY_CONNECTION_FAILED` после того, как
  приложение было закрыто аварийно в режиме Proxy (снято установщиком при
  обновлении, упало, Windows выключилась при подключённом VPN). При старте
  приложение выключает оставшийся системный прокси `socks=127.0.0.1:<порт>`,
  если на этом порту никто не слушает; установщик и деинсталлятор сбрасывают
  его сразу после завершения процесса. Деинсталлятор теперь завершает
  запущенное приложение перед удалением.

## v1.4.0 — 2026-08-17

### Новое
- Переработан интерфейс: понятные названия секций, отдельная «Диагностика»,
  экраны загрузки вместо пустых блоков, окно «Что нового» после обновления.
- Смешанный ввод исключений: домены и IP можно вставлять одним списком —
  приложение само раскладывает их по нужным полям.

### Улучшения
- Локальный SOCKS-порт: если 10808 занят (другой VPN-клиент, зарезервированный
  Windows диапазон портов), берётся свободный порт вместо ошибки
  «bind: Only one usage of each socket address…». Выбранный порт печатается
  в журнале.
- Определение физического шлюза на Windows идёт через IP Helper API
  (`GetIpForwardTable2`) вместо PowerShell: не мелькает консоль, учитываются
  метрики интерфейсов, работает на Windows 7.
- Системный прокси на Linux/macOS/Windows восстанавливается в исходное
  состояние (прежние значения), а не сбрасывается в «нет прокси».
- Очистка маршрутов и прокси доводится до конца, даже если один из шагов
  падает: остальные шаги всё равно выполняются, ошибки собираются вместе.
- Подсети `netsh` и другие подпроцессы Windows больше не мигают консольным
  окном.

### Исправления
- Перезапуск от администратора: elevated-процесс ждёт фактического завершения
  старого по PID и только затем проверяет single-instance mutex. Раньше при
  неудачном тайминге новый процесс тихо выходил — выглядело как «приложение не
  запускается» после подтверждения UAC. Отказ от UAC больше не разрывает
  активное соединение.
- Список серверов и настройки не расходятся с диском: при неудачной записи
  `state.json` состояние в памяти откатывается назад.
- Журнал не дублирует строки при старте (снимок логов и живой поток больше не
  накладываются друг на друга).
- Пустой список серверов при старте не показывается, пока состояние ещё
  загружается с диска.

## v1.3.1 — 2026-07-02

### Исправления
- Перезапуск от администратора (включение TUN): TUN/xray теперь гасится
  синхронно до запуска elevated-процесса, а не после. Раньше при неудачном
  тайминге новый процесс видел мьютекс однократного запуска ещё занятым
  старым и тихо завершался до старта — выглядело как «приложение не
  запускается» после подтверждения UAC.
- Автообновление: подстраховка на случай релиза, где по ошибке опубликован
  только Windows 7 установщик — обычные Windows 10/11 больше не подхватят
  его через общий fallback.

## v1.3.0 — 2026-07-02

### Новое
- Пресет **Claude (Anthropic)** в списке сервисов для whitelist-маршрутизации.
- Простой/расширенный режим настроек — переключатель наверху Настроек, скрывает
  редко используемые секции (маршрутизация, логи) для новых пользователей.

### Улучшения
- Telegram перенесён в общую сетку пресетов сервисов (как единый переключатель),
  по-прежнему включён по умолчанию.
- Настройки разбиты на сворачиваемые секции вместо одной длинной страницы.
- Пресеты сервисов и переключатель режима теперь выглядят как тумблеры.
- Ошибки показываются всплывающими уведомлениями с автоскрытием вместо
  статичного текста.
- При пустом списке серверов приложение сразу открывает Настройки и подсвечивает
  поле для ссылки.
- Результат проверки пинга сервера окрашен по задержке (зелёный/жёлтый/красный).
- Подсказка при наведении поясняет, что делает переключатель Mux.

### Исправления
- Индикатор состояния подключения (кнопка питания) больше не выглядит одинаково
  при отключении и при ошибке подключения.
- Кнопка «Выйти» в диалоге закрытия визуально отделена от основного действия
  «Свернуть в трей», чтобы её было сложнее нажать по ошибке.

## v1.2.1 — 2026-06-22

### Исправления
- Авто-обновление выбирало установщик случайно из двух (Windows 10 и Windows 7),
  появившихся в v1.2.0 — на Windows 10/11 мог скачаться Win7-установщик. Теперь
  установщик выбирается по версии ОС: Win10+ → обычный, Win7/8 → windows7.

## v1.2.0 — 2026-06-22

### Новое
- Отдельная сборка для **Windows 7 SP1 / Server 2008 R2** —
  `kub-connect-vX.Y.Z-windows7-amd64-installer.exe`. Собирается патченным
  toolchain XTLS go-win7 (официальный Go 1.21+ на Win7 падает при старте).
  Обычный установщик по-прежнему требует Windows 10+. Требования к Win7:
  обновления KB2533623, KB4474419 и WebView2 Runtime (см. docs/INSTALL.md).

## v1.1.3 — 2026-06-16

### Исправления
- Повторный запуск приложения больше не открывает второй экземпляр: новый
  запуск разворачивает уже работающее окно (в том числе из трея) и завершается.
- TUN-режим: исправлено подключение на системах с сетевым адаптером, названным
  не латиницей (например «Беспроводная сеть»). Раньше маршруты не применялись с
  ошибкой netsh, потому что имя адаптера портилось из-за кодировки вывода
  PowerShell. Теперь используется числовой индекс интерфейса.

## v1.1.2 — 2026-06-15

### Улучшения
- При удалении приложения деинсталлятор спрашивает, удалить ли настройки и
  данные (сервера, настройки, geo-базы, драйвер TUN). По умолчанию данные
  сохраняются — чтобы переустановка не сбрасывала список серверов и настройки.

## v1.1.1 — 2026-06-15

### Улучшения
- Настройки маршрутизации стали понятнее: контролы, которые не действуют в
  текущем режиме, теперь скрыты, а не показаны вхолостую. «RU напрямую» видно
  только в режиме «Всё через VPN», Kill switch — только там, где он реально
  работает (TUN + поддерживаемая ОС). Заголовки и пункты переименованы
  по-человечески, под каждым контролом добавлены короткие пояснения.

## v1.1.0 — 2026-06-15

### Возможности
- Обновление из приложения (Windows): по кнопке «Обновить» в баннере приложение
  само скачивает установщик новой версии с индикатором прогресса, запускает его
  (с запросом прав администратора) и закрывается для установки поверх. Ссылка на
  скачивание в браузере осталась как запасной вариант.
- Установщик определяет уже установленную версию и предлагает обновление, закрывая
  запущенное приложение перед установкой.

## v1.0.14 — 2026-06-11

### Возможности

- В релиз идёт Windows NSIS-installer (а не голый .exe).

  пинга при ре-рендере, безграничный рост логов и двойное добавление сервера.

## v1.0.0 — 2026-06-09

Первый публичный релиз под брендом KUB Connect.

### Возможности
- VLESS+Xray клиент с whitelist-маршрутизацией (Telegram + кастомные IP/домены).
- **Windows:** режимы Proxy и TUN.
- Встроенные geo-базы (geoip/geosite) — отдельная установка не нужна.
- GUI на Wails: управление серверами, выбор режима, уровень логов.
- Автопроверка обновлений — баннер при выходе новой версии.

### Известные ограничения
- Kill switch не реализован.
- Windows-бинарь не подписан (SmartScreen warning).
